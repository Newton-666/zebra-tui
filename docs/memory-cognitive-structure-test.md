# Krystal 记忆「认知结构」只读测试协议

> 给评测方（人或另一个 AI）直接执行。  
> 目标：判断现有 memory graph 是 **标签共现图** 还是 **认知结构图**。

## 硬约束

1. **不准动源代码**（不改 `zebra tui` 内任何实现文件）。
2. **不准改已有记忆**（不写入 / 修改 / 删除 / supersede `~/.krystal/`）。
3. **不准复杂化**（不新建子系统、不上向量库、不跑 `/sleep`、不加策展模型）。
4. 只用只读材料：`facts.jsonl`、`MEMORY.md`，或只读查询结果（`about` / `related` / `connect` / `conflicts`）。  
   禁止：`remember` / `supersede` / `helpful` / `wrong` / `/sleep` 及任何会写盘的 memory op。

## 路径与口径

| 项 | 值 |
|----|-----|
| 项目 | `/Users/niuqingwei/Desktop/zebra tui`（可只读；非必须改它） |
| 记忆库 | `~/.krystal/facts.jsonl`、`~/.krystal/MEMORY.md` |
| 活跃事实 | 未被 `supersede` 的 fact |
| 全局图 | 无 `scope` 的事实（主判）；团队子图可附注，不计入主分档 |

## 操作定义

- **标签共现图**：节点靠共享 `entities[]`（或同条内实体两两共现）相连；关系类型读不出来。
- **认知结构图**：对选定主题，能从 **图结构**（不只读 `text` 脑补）稳定读出三类关系：
  - **因果** causes / prevents / leads-to
  - **立场** contradicts / supports / updates（含 supersede 链）
  - **依赖** part-of / requires / uses

> 模型把 `text` 读完能复述故事 ≠ 通过。必须看结构是否承载关系。

## 选主题

选 **1** 个主题，满足：

- 全局活跃事实 **≥ 8**
- 最好含 supersede 或 conflicts 线索
- 优先事实较密、能讲清一条故事线的实体 hub

记录下来：

- 主题名
- 相关实体列表
- 纳入的事实 `id` 列表

## 步骤

### A. 基线导出（只读）

1. 列出主题下活跃事实：`id, text, entities, trust, used, supersededBy?`
2. 列出 **机器结构边**：仅「共享同一 entity 字符串」或「同条 fact 内实体共现」——不要发明关系类型
3. 另表列出 `text` 里 *看起来像* 因果 / 立场 / 依赖的句子（仅对照，**不算**结构证据）

### B. 认知探针（标注，不改库）

对纳入的事实对，尝试标三类边（可为「无」）。

判定规则：

| 标注 | 条件 |
|------|------|
| `结构可读` | 图上已有结构支撑（如 supersede 链 → updates；conflicts → contradicts 候选） |
| `仅文本` | 关系只在自然语言里，图上仅有实体共现 |
| `无` | 金标也不认为存在 |

禁止为凑关系假设未存储的边。

### C. 对照金标

1. 同一批事实，评测方画一张「应有认知图」（可含类型边）
2. 差集：
   - 金标有、机器结构无 → **缺口**
   - 机器共现有、金标无语义 → **标签噪声 / hub**

## 评分

| 档 | 标准 |
|----|------|
| **标签图** | 三类里结构可读 **&lt; 2 类**；主要靠实体共现 |
| **过渡** | 恰好 **2 类**结构可读（常见：supersede / conflicts）；因果或依赖仍靠读 text |
| **认知结构** | **3 类**都能从结构稳定读出，且 hub 噪声不淹没主链 |

**本测试「达到认知」的通过线**：认知结构档。

> 基于当前架构的预期：多半为「标签图」或「过渡」（边无类型；sleep 几乎不重组拓扑）。预期不是失败，是基线。

## 交付物

评测方只交以下内容：

1. 主题与事实 id 列表
2. 机器共现图摘要（节点数、边数、top hub 实体）
3. 三类关系表：`事实A → 关系 → 事实B`，每行标注 `结构可读 | 仅文本 | 无`
4. 与金标的差集（缺口 / 噪声）
5. 最终分档 + **一句话结论**
6. 可选：≤3 条观察（薄 harness 前提下如何仍要结构——建议级，**不实现**）

## 明确不要做

- 改代码、写记忆、跑 `/sleep`、导入新事实「补全」测试
- 上向量检索、新建 edge 表、做模型策展
- 用「能复述」代替「结构可读」

## 一句话指令（可复制给评测 AI）

> 只读现有图；若抽不出带类型的因果 / 立场 / 依赖结构边，就判未达认知结构——即使文本里写得很清楚。不准动源码，不准改记忆，不准复杂化。
