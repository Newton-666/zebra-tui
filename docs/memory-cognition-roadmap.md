# Krystal 记忆 → 认知：第一性原理路线图

> 原则：极简 harness · 判断交给模型 · 不复杂化 · 压缩=搬迁不删 · 可审计。  
> 现状锚点：typed link 原语已通（含工具接线）；真实库仍以共现为主；sleep 偏降权。

## 1. 第一性原理（只保留三问）

| 问 | 含义 | 系统只提供 |
|----|------|------------|
| **痕迹** | 什么值得留下？ | `remember` / `supersede`（显式，不静默抽） |
| **结构** | 留下的如何相连？ | 命题节点 + **可选** typed link + 实体索引（共现兜底） |
| **提取与巩固** | 何时调出、如何变清楚？ | 纯检索召回 · supersede 可见 · sleep 做轻度图式整理 |

不做：全脑仿真、向量当主索引、硬分类器替模型做判断、为时空单独建一套引擎。

## 2. 目标形态（一句话）

**薄 harness 上的可审计认知图**：存的是可组合的判断与有类型的关系；用的是按关系导航的召回；睡是重组与降噪，不是清盘。

验收直觉：抽一个主题，不读长 `text` 脑补，也能走出因果 / 立场 / 依赖。

## 3. 阶段（按依赖，不按炫技）

### 阶段 0 — 基线（已完成）
- 显式编码、append-only、supersede 版本链
- 纯检索（记忆不预装进 system）
- 评测协议证明：曾是**标签共现图**

### 阶段 1 — 立场可见（已完成）
- 读路径暴露 `replaces` / `supersededBy`
- 产品诚实：已取代条默认取不回全文

### 阶段 2 — 关系可编码（能力完成 · 数据待积累）
- 可选 typed link 词表：`updates · contradicts · causes · depends_on · part_of`
- 工具路径已接线（`executeTool` 传 `links`）
- **门禁**：真实使用中边开始出现；同一主题评测 ≥2/3 类结构可读

### 阶段 3 — 提取像认知（下一步主线）
- 召回默认优先 typed 邻域，共现降为兜底
- 链头 / 出边 /（可选）入边摘要在工具结果里可扫
- 双活跃无箭头：靠模型 `updates` 或 supersede，不自动瞎合并
- **门禁**：关键主题能回答「谁更新了谁 / 什么导致了什么 / 依赖谁」且主要走边

### 阶段 4 — 巩固像睡眠（再下一步）
- sleep：去重 + 降权之外，允许**可选**结构整理（合并同义、提示/协助 supersede、轻量 retag）——仍交模型或确定性规则，不强制大策展
- undo 完整（含结构调整）
- **门禁**：sleep 后图式更清晰，可回滚；不引入新子系统

### 阶段 5 — 情节线索（可选，不阻塞主线）
- 时间：多用 `created/updated` + 可选 `before`
- 情境：实体 / 短 context，而非空间引擎
- 与 `compaction-graph`（决策图）对齐：延续的是思路流，不是状态快照

## 4. 明确不做（保极简）

- 静默全量抽取记忆或关系
- 开放 ontology / 任意字符串关系名
- 向量库替换图为唯一真源
- 未获同意改写真实 `~/.krystal` 历史

## 5. 近期行动序（建议）

1. **用**：让 solo bot 在真实任务里开始写 `links`（积累数据）
2. **测**：复跑认知结构协议，看真实库类数是否离开 1/3
3. **提**：阶段 3 小改——召回排序/展示偏向 typed
4. **睡**：阶段 4 再开任务书（先协议，后动手）
